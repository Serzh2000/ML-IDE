# История изменений

## 0.5.3
- **Каталог из 130 учебных наборов** (детекция, сегментация, повёрнутые рамки, ключевые точки, классификация): без регистрации, из Ultralytics и Hugging Face (Roboflow 100), с поиском и фильтрами; из больших наборов качается только выборка кадров. Свой набор Hugging Face по имени, обновление каталога по кнопке.
- **Портативная версия** (`ML-IDE-<версия>-portable.zip`): настройки и примеры в папке `data` рядом с программой. Установщик задаёт язык интерфейса по языку мастера.
- Язык интерфейса при первом запуске выбирается по языку системы (русский / английский), меняется в меню «Вид → Язык».

## 0.5.2
- **Исправлено:** обучение, запущенное из приложения, падало с кодом 0xC0000005 (дочерний Python подхватывал DLL из папки приложения). Теперь запуск чистит окружение; при прерывании окно объясняет причину и что делать.
- **Исправлено:** `.onnx` не открывался по пути с кириллицей; экспорт без проверочной части (val) давал неработающий data.yaml.
- Окно экспорта прокручивается и помещается на малых экранах; обучение предлагает открыть экспорт, если нет train.py.
- Проверка модели: выбор камеры из списка, видео и **одиночное фото**; `.pt` без ultralytics автоматически заменяется на `.onnx`.
- Схема модели открывается в **Netron** (локально, без статистики); прежняя сводка слоёв осталась отдельным пунктом.

## 0.5.1
- Обучение: если в папке нет train.py, предлагается сразу открыть экспорт и продолжить обучение.
- Окно экспорта прокручивается и помещается на малых экранах; исправлено обрезание текста на кнопках.
- Экспорт: если все кадры признаны похожими и проверочная часть пуста, делается случайное разбиение с предупреждением; в data.yaml всегда есть ключ val.

## 0.5.0
- **Новые задачи:** повёрнутые рамки (OBB, инструмент `O`), ключевые точки (pose, `K`, Правка → Настроить ключевые точки),
  классификация изображений (`T`); экспорт YOLO OBB / Pose / Classify (проверен 1 эпохой обучения Ultralytics для каждой задачи),
  импорт папок «класс = папка», примеры DOTA8, COCO8-pose и MNIST160.
- **Дизайн:** единый набор векторных значков Lucide вместо эмодзи, светлая и тёмная тема, значки состояния в списке изображений.
- Проверка обновлений (по кнопке), установка PyTorch с CUDA под вашу видеокарту.
- Инструмент «Клик (SAM)» добавлен на панель; английский перевод вычитан; тесты не пишут в настройки пользователя.
- Проверено: установщик (установка, запуск, удаление), скачивание модели SAM, ручное тестирование мышью и клавиатурой.

## 0.4.0
- **Разметка по клику (SAM):** MobileSAM (ONNX), инструмент `G`; модель скачивается один раз с согласия пользователя.
- **Качество данных:** поиск дублей и похожих кадров; разбиение train/val без утечки; проверка разметки обученной моделью
  (ошибки, «что размечать дальше»); объединение и порядок классов.
- **Импорт:** COCO JSON и Pascal VOC; кадры из видео.
- **Анализ:** сравнение запусков обучения; тест модели на видео/веб-камере и замер FPS; примеры кода; помощь с видеокартой (CUDA).
- **Надёжность:** резервная копия проекта (.bak) и восстановление, поиск перемещённых файлов, снимки разметки, недавние проекты,
  виртуальный список изображений (20 000 изображений: обновление списка 1.6 с -> 0.07 с).
- **Английский интерфейс** (Вид → Язык / Language), `README.en.md`, установщик (Inno Setup), самопроверка exe (`--selftest`).
- Включает функции 0.3: экспорт модели (ONNX, OpenVINO, TensorRT, NCNN, TFLite, CoreML, ESP32-S3), просмотр графа ONNX.

## 0.3.0
- «Экспорт модели»: ONNX, TorchScript, OpenVINO, TensorRT, NCNN, TFLite, CoreML и подготовка для **ESP32-S3 / ESP32-P4**
  (ONNX 320 px + калибровочные картинки для квантования ESP-PPQ).
- «Просмотр модели»: схема графа ONNX, сводка (параметры, вход/выход простым языком), список слоёв, пояснение каждого слоя.
- Справочник: руководство «Развёртывание на ESP32-S3».

## 0.2.0
- Новый дизайн: единая тёмная тема, иконка приложения, стартовый экран.
- «Примеры»: шесть учебных наборов (детекция и сегментация), скачиваются по кнопке.
- Тур по приложению (14 шагов) и подсказки при наведении на все параметры.
- «Результаты обучения»: метрики, графики, матрица ошибок, проверка модели на любом фото.

- Экспорт: заморозка слоёв, шаг обучения (lr0), patience.
